# Carnet du jour

Petit carnet de tâches quotidiennes pensé pour un cerveau TDAH : une seule chose à la fois, des rappels doux et aléatoires sur l'iPhone (via l'app gratuite [ntfy](https://ntfy.sh)), une mémoire qui apprend les habitudes, et une ambiance d'automne.

- Tout reste sur le téléphone (aucun compte, aucun serveur à soi).
- Fonctionne hors ligne une fois installé sur l'écran d'accueil.
- Déployé avec GitHub Pages depuis la branche `main`.
